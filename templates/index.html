WhistleShield Secure Channel

Aplikasi ini mendukung pengirim anonim dan penerima dengan peran admin. Semua pesan terenkripsi end-to-end dan disembunyikan dalam foto.

Anonim + Admin
Anda siapa?
Sistem ini menggunakan enkripsi RSA-2048 OAEP end-to-end + steganografi DCT. Pilih peran Anda untuk memulai. Private key tidak pernah meninggalkan browser Anda.

Penerima (Admin)

Admin akan membuka room, menerima laporan, dan membaca pesan rahasia dari whistleblower.

Pengirim (Anonim)

Whistleblower atau pelapor anonim. Masukkan Room ID penerima dan kirim pesan tersembunyi dalam foto.
